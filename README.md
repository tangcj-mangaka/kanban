# 驴看板

一个个人用的看板应用，Windows 桌面端 + Android 手机端，数据在设备间实时互通。

和常见的看板不一样：**没有列**。每个看板是一块自由画布，卡片随意摆放拖动，分类完全靠标签。另有一个按标签自动分列的分组视图用来俯瞰。归档区叫**干草仓库**。

数据**本地优先**——每台设备存一份完整数据，离线照样能完整增删改查。同步只是有网时的后台行为，服务端不在线不影响任何设备使用。

## 开发环境

**在 Mac 上开发，Windows 的 `.exe` 由 GitHub Actions 云端构建。** 不需要任何 Windows 开发环境。

Flutter 无法在 macOS 上编译 Windows 桌面应用（依赖 MSVC 工具链，且不存在交叉编译方案）。但这只是**出包**的限制——P1 的全部内容都是平台无关的，在 macOS 桌面版上开发和验证即可。

### 日常开发（Mac）

```bash
cd packages/app && flutter run -d macos
```

```bash
cd packages/app && flutter analyze
```

### 拿 Windows 版

push 到 `main` 后，GitHub Actions 自动构建。到仓库的 **Actions** 页面下载 `kanban-windows` 产物，解压双击 `kanban.exe` 即可运行，目标机器不需要装任何东西。

也可以在 Actions 页面手动触发（`Run workflow`）。

### 已知的平台差异

在 macOS 上开发、最终跑在 Windows，以下地方需要在出包后实机确认一次：

- 中文默认字体不同（苹方 vs 微软雅黑），行高与字重观感有差异
- 滚动惯性、触控板手势
- 快捷键 `Cmd` / `Ctrl`
- 窗口标题栏样式、应用数据目录位置
- **P2 的托盘常驻和开机自启是 Windows 专属能力，Mac 上无法验证**，到那个阶段需要在 Windows 机器上实测

### P1 已实现

- **看板列表**：网格布局，新建 / 重命名 / 改封面色 / 删除（强确认）/ 拖动排序 / 按名称过滤
- **画布视图**：无限画布，卡片自由拖放、可调宽度、可折叠；滚轮平移、⌘+滚轮缩放、空格或中键拖拽平移；双击空白处建卡；一键整理成网格、适应全部
- **卡片**：标题、Markdown 正文（工具栏 + 预览）、颜色、多标签、评论、归档、删除
- **标签**：板内专属，可新建 / 重命名 / 改色 / 拖动排序 / 删除（只解除关联，卡片保留）
- **分组视图**：按全部标签自动分列 + 未分类，不可拖动，多标签卡片在每列各出现一份；可切换列内排序、隐藏空列
- **干草仓库**：可搜索、按标签筛选、单张捞回或彻底删除、清空全部（强确认）
- **底层**：op log 为真相源，字段级 LWW + 墓碑删除 + 小数序，为 P2 同步预留

### P2 已实现

- **服务端**：op log + 全局序号分配 + 广播中枢，不理解数据模型、从不物化
- **同步**：字段级 LWW、离线队列、自动重连、ACK 重放、编辑态提示
- **配对**：终端二维码 + 连接链接 + 6 位一次性配对码，三条路都留着
- **局域网自动发现**：UDP 广播，客户端设置页自动列出服务端
- **控制面板**：`http://localhost:8765`，看设备、备份、开关开机自启（仅本机可访问）
- **开机自启**：Windows 注册表 Run 项 + 隐藏窗口启动

启动服务端：

```bash
kanban-server.exe
```

### P3 已实现

- **按内容哈希存储**：同一张图在多张卡片里用只占一份磁盘，重复上传秒传
- **缩略图**：客户端生成（服务端不装图像库），长边 400px，小图不再生成
- **离线可用**：加附件只写本地，联网后自动补传；未传的标「待同步」
- **本地缓存**：上限 500MB，按最近最少使用淘汰，**绝不删还没传上去的**
- **断点续传**：下载支持 Range
- **延迟回收**：没人引用的文件先记成孤儿，30 天后才真删

### P4 已实现

- **Android 构建通了**，模拟器上跑通了完整的跨设备同步（Mac 推 250 条 → 手机全量拉下来）
- **清单配置**：正式版的 `INTERNET` 权限、明文流量（局域网服务端是 http/ws）
- **响应式**：窄屏顶栏只留图标、弹窗占满、搜索框自适应、工具条换行
- **手机默认进分组视图**：整屏一列、左右滑动切换，顶部列名标签条
- **触控手势**：画布双指捏合缩放、拖空白处平移（手机上没有滚轮和空格键）

构建 APK：

```bash
cd packages/app && flutter build apk --release
```
